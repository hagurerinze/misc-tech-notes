# Hagure's Misc Tech Notes

A collection of tech notes that don't fit into my main
[low-spec-laptop](https://github.com/hagurerinze/low-spec-laptop) repo —
troubleshooting sessions, AI tool experiments, and other one-off technical
digging that didn't belong to a single focused project.

## Purpose

- Keep a record of troubleshooting and experiments that are still worth
  documenting, even when they're outside the low-spec-laptop scope.
- A place for AI-tool session logs, cross-platform (Windows/WSL) notes,
  and small technical experiments.

## Categories

- **Windows / WSL** — [WSL Debian Ghost Cleanup](./windows_wsl_debian_ghost_cleanup.md)
- **AI Tool Sessions** — notes from testing AI coding/image/video tools
- **Experiments** — small technical test logs (e.g. game save file editing)

## About me

I run Debian on a low-spec laptop and enjoy digging into how systems
actually work under the hood. This repo is the overflow bin for notes
that are still worth keeping, but don't belong in a single focused
project repo.

I use AI tools during development, but every note here reflects something
I actually tested, debugged, and understood myself.
